# עיצוב קרוסלה לאינסטגרם

מייצר קרוסלה מוכנה להעלאה: רצף שקפים בגודל **1080x1350** (4:5), שמערבב **תמונות סטילס** (JPEG) ו**סרטונים** (MP4). הסגנון: תמונה/וידאו במסך מלא, טקסט **לבן עם קונטור שחור** למעלה/למטה/במרכז, סימן קלוד ובאדג'ים כתומים ממוספרים, ואקסנט של **פונט כתב יד "דנה יד" בצהוב**.

הפלט האחרון שנבנה: `~/Desktop/קלודתון/קרוסלה-קלוד/` (12 שקפים, 4 סרטונים) — "7 דרכים שאני משתמשת בקלוד בעסק".

## Pipeline

1. **סטילס** נבנים דרך Puppeteer: כל שקף הוא HTML שמצולם ל-JPEG.
2. **שקפי וידאו** נבנים דרך ffmpeg: מטביעים שכבת טקסט שקופה (PNG שרונדר ב-Puppeteer) על גבי סרטון חתוך ל-1080x1350.
3. הפלט: `slide-01.jpg`, `slide-02.jpg`, ... כש-slide שהוא וידאו מקבל סיומת `.mp4`. **הסדר נקבע לפי מספר הקובץ** (העלאה לאינסטגרם לפי הסדר).

הקובץ המרכזי הוא `assets/build.js` — תבנית עבודה מלאה (מייצר את כל הסטילס + שכבות הוידאו השקופות). **התאם אותו** לכל קרוסלה: ערוך את מערך `slides` ואת הטקסטים, והעתק את התמונות/פונטים ל-`assets/` של תיקיית העבודה.

### הרצה (תבנית קבועה)

```bash
# תיקיית עבודה (למשל ~/Desktop/<שם>/קרוסלה/), עם assets/ שמכיל את התמונות + הפונטים
cd /path/to/workdir
node build.js            # מרנדר את כל הסטילס + overlay-*.png לשקפי הוידאו
rm -f _tmp_*.html        # ניקוי קבצי HTML זמניים
# ואז ffmpeg לכל שקף וידאו (ראה references/ffmpeg-recipes.md)
```

- Puppeteer מותקן ב-`/tmp/node_modules/puppeteer` (התקנה אם חסר: `cd /tmp && npm install puppeteer`).
- `build.js` מפנה ל-`/tmp/node_modules/puppeteer` וטוען Heebo מ-Google Fonts (צריך אינטרנט) ו-Dana Yad מ-`assets/DanaYad.otf`.
- fresh browser לכל שקף (ראה גוצ'ה למטה).

## מערכת העיצוב

- **מידות:** 1080x1350, `deviceScaleFactor: 2` (פלט 2160x2700, חד לאינסטגרם).
- **פונטים:** כותרות וגוף = **Heebo** (900/800, הכי קרוב ל-Instagram Classic עם תמיכה טובה בעברית). אקסנט = **Dana Yad** (`assets/DanaYad.otf`, `font-display:block`) בצהוב `#FFCE33`, בלי קונטור.
- **טקסט לבן עם קונטור שחור:** `-webkit-text-stroke` + `paint-order:stroke` (הקונטור מאחורי האותיות, נקי). קבועים ב-build.js: `STROKE_TITLE` (8px), `STROKE_SUB` (4px), `STROKE_BODY` (3px, לגוף ארוך יותר לקריאוּת).
- **צבע קלוד:** כתום החומר `#D97757` (באדג'ים, כפתורים, סימן).
- **סימן קלוד:** פונקציית `burst()` מציירת שמש/כוכב של 12 קרניים ב-SVG. `claudeIcon()` = ריבוע כתום מעוגל עם ברסט לבן (כמו אייקון האפליקציה). ללוגו המלא (שמש + Claude wordmark) יש `assets/claude-logo.png`.
- **גרדיאנטים:** `GRAD_TIP` (כהה למעלה+למטה, בינוני באמצע) — מאפשר טקסט קריא בכל עוגן. שכבות טקסט וידאו: גרדיאנט כהה בצד שבו הטקסט (למעלה או למטה).
- **RTL:** `dir="rtl"`. יישור מרכזי לרוב השקפים.

## סוגי שקפים (כל אחד = פונקציה ב-build.js)

- **פתיח / מניפסט** (`introSlide1/2`): טקסט כבד על תמונה מעומעמת, ממורכז. פותח את הנרטיב ("מה שמייחד בני אדם מ-AI... הנה מה שאני משתמשת בו").
- **שער** (`coverSlide`): לוגו קלוד למעלה-שמאל, כותרת "N דרכים...", תת-כותרת בדנה יד צהוב, וחץ ➡️ (`arrowRight()`). התמונה במסך מלא.
- **טיפ ממוספר** (`tipSlide`): רקע תמונה, שורת באדג' (ברסט + מספר כתום), כותרת גדולה, וגוף של **2 משפטים מלאים**. פרמטר `anchor` (`top`/`center`/`bottom`) קובע מיקום אנכי — משתמשים בו כדי **שהטקסט לא יעלה על הפנים**.
- **טיפ וידאו** (`videoOverlay*`): רק שכבת הטקסט (שקופה, `omitBackground`) עם גרדיאנט מוטבע; הרקע הוא הסרטון (מוטבע ב-ffmpeg). מושתק ולופ.
- **הוכחות חברתיות** (`socialProofSlide` + `proofCard`): כרטיסי צילומי-מסך לבנים, מסובבים קלות, מדורגים בקסקדה על רקע תמונה. מוסיף אמינות לפני ה-CTA.
- **CTA** (`ctaSlide`): כותרת שאלה, שורת דנה יד צהוב, כפתור-פיל כתום ("הגיבי 'קלוד'"), וחתימה. **בלי תאריך/יום** אם רוצים שיהיה שמיש למחזורים הבאים.

מבנה נרטיבי מומלץ: `פתיח x2 → שער → טיפים ממוספרים → הוכחות חברתיות → CTA`.

## גוצ'ות טכניים (חשוב — נלמדו בדם)

- **צילום clip מחזיר תמונה לבנה ב-`deviceScaleFactor:1`.** ב-headless Chrome הזה, `screenshot({clip})` יוצא ריק ב-dSF1 אבל תקין ב-dSF2. **תמיד dSF2.**
- **בנייה ברצף באותו browser קורסת (timeout) אחרי ~4-5 שקפים גדולים.** הפתרון: **launch browser חדש לכל שקף** (ה-build.js כבר עושה זאת). איטי יותר, אבל יציב.
- **טקסט על הפנים:** משלבים `object-position` (איזה חלק מהתמונה מוצג) עם `anchor` (איפה הטקסט אנכית). דוגמה: פנים גבוהות בפריים (`object-position:center 74%`) + `anchor:'center'` → הטקסט נוחת על החזה/מקלדת, לא על הפנים. **תמיד לרנדר ולראות בעיניים, ולתקן מיקום אם צריך.**
- **בעיות bidi ב-RTL:** ידית לטינית (`@handle`) או "AI" בסוף שורה מתהפכות. פתרונות: לעטוף ב-`<span dir="ltr" style="unicode-bidi:isolate">`, או פשוט לכתוב בעברית ("בינה מלאכותית" במקום "AI").
- **מקף ארוך (—) אסור** בתוכן (חוק מותג של הסטודיו). להשתמש בפסיקים/נקודות/שורות.
- **שכבת וידאו שקופה:** מרונדרת ב-dSF2 (2160x2700) עם `omitBackground:true`; ב-ffmpeg עושים לה `scale=1080:1350` לפני ה-overlay.
- **חיתוך וידאו ל-4:5:** מקור 1080x1920 → `crop=1080:1350:0:285` (מרכז). מקור קטן (למשל 576x1024) → `scale=1080:1920` קודם ואז crop. תמיד `-an` להשתקה, `-movflags +faststart`.
- **וידאו inset מוטה:** מטביעים סרטון קטן מסובב בפינה. פילטר `rotate` דורש `ow=rotw(<rad>):oh=roth(<rad>):c=none` (הזווית ברדיאנים, כפונקציה — לא כקבוע חשוף), ו-`format=rgba` לפני הסיבוב לשקיפות.
- **build.js מרנדר מחדש כל slide-NN.jpg בכל הרצה.** אם שקף מסוים הפך לוידאו (slide-07.mp4), מחק את ה-jpg המקביל אחרי כל הרצה כדי שהתיקייה תישאר נקייה.

כל המתכונים המדויקים של ffmpeg (שקף וידאו, inset מוטה, השתקה, לופ) ב-`references/ffmpeg-recipes.md`.

## טון ותוכן

בטון של הסטודיו: שורות קצרות, ישיר, מצחיק, בגוף ראשון נקבה. בלי הבטחות ("מובטח"/מיליונים), בלי מקף ארוך, בלי לשמוע כמו AI. חתימה: **באהבה, שירה ודידי**. פרטי המותג המלאים ב-CLAUDE.md.

## איך להתחיל קרוסלה חדשה

1. צור תיקיית עבודה עם `assets/` והעתק אליה: `build.js`, `DanaYad.otf/woff`, `claude-logo.png` (מ-`assets/` של הסקיל), והתמונות/סרטונים של הלקוחה.
2. ערוך ב-`build.js` את מערך `slides` (טקסטים, תמונות, `anchor`, `pos`) ואת פונקציות השקפים לפי הצורך.
3. הרץ `node build.js`, ואז את פקודות ה-ffmpeg לשקפי הוידאו.
4. **רנדר → צלם frame → הסתכל בעיניים → תקן** (מיקום טקסט, גדלים, חיתוכי תמונה). זה תהליך איטרטיבי.
5. נקה קבצים זמניים (`_tmp_*.html`, `overlay-*.png`, jpg מיותרים של שקפי וידאו) ופתח את התיקייה למשתמשת.
