# קרוסלה חמה בכתב יד (Warm / Cloud-boxes)

מייצר קרוסלה מוכנה להעלאה: שקפים **1080x1350** (4:5) בסגנון חם ואישי, בהשראת פוסטים אורגניים. הסגנון: תמונה ברקע, **בועות "ענן" עם קצוות מסולסלים**, **פונט כתב יד "Gveret Levin"** לגוף הטקסט, **כותרות בולד** (Heebo 800), וי'ים מתחלפים בשני צבעים, **חץ מצויר ביד** להחלקה, וה-**@handle** של העסק בתחתית כל שקף.

## לפני שמתחילים: לשאול את המשתמשת

לפני שבונים, לברר (בשאלה אחת קצרה, לא חקירה):

1. **מה ה-handle באינסטגרם?** (למשל `@my_studio`). אם אין או לא רוצה, משאירים ריק והשורה לא מופיעה.
2. **צבעים:** להציע את הפלטה החמה המוכנה (חום `#5b4736`, קרם `#f4e6d6`, טורקיז `#5f8b86`), או לקבל צבעי מותג משלה. צריך 3 צבעים: כהה (לכתב היד ולקופסאות), בהיר (למילוי הבועות), ואקסנט (לוי'ים).
3. **תמונות:** לבקש ממנה תמונות משלה (ים, קפה, סלפי, עבודה, מה שיש). גם תמונות לא "מקצועיות" עובדות מצוין בסגנון הזה.
4. **נושא הקרוסלה** ומה הקריאה לפעולה בסוף.

**טון ומותג:** אם יש לה קובץ CLAUDE.md או הנחיות מותג, לכתוב לפיהן. אם אין, לכתוב בשפה פשוטה, חמה ואישית, שורות קצרות, בלי הבטחות מוגזמות ובלי ניסוחים שנשמעים כמו AI.

## Pipeline

1. כל שקף הוא HTML שמצולם ל-JPEG דרך Puppeteer (browser חדש לכל שקף, בשביל יציבות).
2. **בועות הענן נמדדות ומצוירות בזמן ריצה בתוך הדף**: סקריפט (`PAGE_JS`) מודד את תיבת הטקסט אחרי שהפונטים נטענו, ומזריק מאחוריה SVG של מלבן מסולסל בגודל המתאים. Puppeteer ממתין ל-`window.__cloudsReady===true`.
3. פלט: `slide-01.jpg`, `slide-02.jpg`, ... **הסדר לפי מספר הקובץ** (העלאה לאינסטגרם לפי הסדר).

הקובץ המרכזי הוא `assets/build.js`: תבנית עבודה מלאה עם כל אבני הבניין ודוגמת קרוסלה של 6 שקפים. **מתאימים אותו** לכל קרוסלה: ממלאים את `BRAND` בראש הקובץ, עורכים את מערך `slides`, ומעתיקים את התמונות ל-`assets/`.

## הרצה (מק וווינדוס)

צריך **Node.js** מותקן (nodejs.org). אם אין, להסביר למשתמשת איך להתקין לפני שממשיכים.

```bash
# בתוך תיקיית העבודה (שבה נמצאים build.js ו-assets/)
npm install puppeteer      # פעם אחת בלבד לכל תיקייה
node build.js              # מרנדר את כל השקפים
```

- כדי לדרוס שקפים קיימים: במק `FORCE=1 node build.js`, בווינדוס (PowerShell) `$env:FORCE=1; node build.js`.
- ניקוי קבצים זמניים: במק `rm -f _tmp_*.html`, בווינדוס `del _tmp_*.html`.
- הפונטים נטענים מ-Google Fonts (צריך אינטרנט): **Heebo** לכותרות, **Gveret Levin** לכתב יד.
- אם תמונה חסרה ב-`assets/`, השקף ייבנה עם רקע צבעוני רגיל במקום לקרוס.
- **תמיד לרנדר, להסתכל בעיניים, ולתקן** מיקום, גדלים וחיתוך תמונה. זה תהליך איטרטיבי.

## מערכת העיצוב

- **מידות:** 1080x1350, `deviceScaleFactor: 2` (פלט 2160x2700, חד לאינסטגרם).
- **פונטים:** כותרות = **Heebo** 800 (בולד עגול). גוף/כתב יד = **Gveret Levin** (`.hand`), תמיד בצבע הכהה.
- **פלטה** (באובייקט `BRAND` בראש build.js):
  - `handle`: ה-@ שמופיע בתחתית כל שקף (`''` = בלי)
  - `dark`: טקסט כתב יד, קופסאות כהות, וי'ים
  - `light`: מילוי בועה רכה
  - `accent`: הצבע השני של הוי'ים
  - לבן קבוע: מילוי בועה לבנה
- **בועת ענן (`cloud`)**: מלבן עם בליטות חצי-עגולות בכל ההיקף. פרמטרים: `fill` (צבע), `bump` (רדיוס הסלסול, ~38-44), `pad`, `maxw`. הבועה **נמדדת אוטומטית** לפי הטקסט.
- **וי'ים מתחלפים**: כהה/אקסנט לסירוגין (`checklistCloud`).
- **חץ מצויר ביד (`arrow`)**: שחור עם הילת "נייר" לבנה, בסגנון סקיצה.
- **@handle**: בתחתית כל שקף (בהיר על תמונה, כהה על רקע בהיר).
- **RTL**: `dir="rtl"`, יישור מרכזי לרוב. טקסט כתב יד לפעמים מיושר לימין בתוך הבועה (צ'ק ליסט).

## אבני בניין (פונקציות ב-build.js)

- **`bg(photo, {pos, blur, bright, scrim})`**: רקע תמונה. `blur`/`bright` לרקע רך ("מטושטש"), `scrim` לגרדיאנט כהה לקריאוּת.
- **`headline(html, {size, color, shadow})`**: כותרת בולד (Heebo). לבן על תמונה, או `color:BROWN` (הצבע הכהה) על רקע בהיר.
- **`hand(html, {size, color})`**: פסקת כתב יד (Gveret Levin).
- **`cloud(inner, {fill, bump, pad, maxw})`**: עוטף כל תוכן בבועת ענן מסולסלת.
- **`numberCloud(n, html, ...)`**: בועה עם מספר גדול (1. / 2.) מעל כתב יד, לשקפי "שני סוגים".
- **`checklistCloud(items, ...)`**: בועה לבנה עם שורות צ'ק ליסט (וי'ים מתחלפים).
- **`solidBox(text, {bg, color, ...})`**: קופסה מעוגלת אחידה (סגנון CTA כהה).
- **`arrow(w)`**: חץ מצויר ביד.
- **`handle({light})`**: שורת ה-@handle.
- **`stack(bgHtml, blocksHtml, {anchor, pad, gap, handleLight})`**: עוטף שקף שלם: רקע + סטאק בלוקים ממורכז + handle בתחתית. `anchor`: `top`/`center`/`bottom`.

(בקוד, `BROWN` = `BRAND.dark`, `CREAM` = `BRAND.light`, `TEAL` = `BRAND.accent`.)

## סוגי שקפים (מבנה נרטיבי מומלץ)

`קאבר (כותרת + בועה + חץ) → ציטוט/הוק (כותרת לבנה על תמונה) → כותרת + בועה × כמה → שני סוגים (2 בועות ממוספרות) → שאלה + בועה → צ'ק ליסט + CTA`

- **קאבר**: `headline` לבן גדול + `cloud(hand(...), {fill:CREAM})` + `arrow()`. עוגן `top`.
- **ציטוט/הוק**: `headline` לבן ישירות על התמונה (בלי בועה), עם `scrim` לקריאוּת.
- **תוכן**: `headline` + `cloud(hand(...))`.
- **שני סוגים**: שתי `numberCloud` (לבנה + בהירה) על רקע מטושטש.
- **צ'ק ליסט / CTA**: `checklistCloud([...])` + `solidBox('הגיבי "מילה" ונשלח לך לינק')`.

## גוצ'ות טכניים (חשוב)

- **בועות הענן דורשות המתנה ל-JS**: תמיד `waitForFunction('window.__cloudsReady===true')` לפני הצילום. אם משנים את מבנה ה-DOM של הבועה, לוודא ש-`.cloudwrap` מכיל `.cloudtext`.
- **קונטרסט על רקע מטושטש/בהיר**: `blur+bright:.6` הופך תמונה בהירה לרקע כמעט אחיד. על רקע כזה **כותרת לבנה נעלמת**: להשתמש ב-`color:BROWN` לכותרת, או להוסיף `scrim` כהה.
- **צבעי מותג בהירים מדי**: אם `dark` בהיר, כתב היד לא ייקרא על בועה לבנה. לוודא שהצבע הכהה באמת כהה.
- **בנייה ברצף באותו browser קורסת** אחרי כמה שקפים, לכן build.js פותח browser חדש לכל שקף (איטי אבל יציב).
- **bidi ב-RTL**: מספרים/לטינית בסוף שורה עלולים להתהפך. לעטוף ב-`dir="ltr"` (כמו ה-handle) או לנסח בעברית.
- **`bump` גדול מדי** על בועה קטנה נותן מעט בליטות (נראה רע). `bump` ~38-44; לבועות קטנות להוריד ל-32.

## איך להתחיל קרוסלה חדשה

1. לשאול את השאלות למעלה (handle, צבעים, תמונות, נושא).
2. ליצור תיקיית עבודה עם `assets/`, להעתיק אליה את `build.js` (מ-`assets/` של הסקיל) ואת התמונות של המשתמשת.
3. למלא את `BRAND` ולערוך את מערך `slides`: טקסטים, תמונה לכל שקף, סוג שקף (בועה/ציטוט/צ'ק ליסט), `pos`/`blur`/`bright`.
4. `npm install puppeteer` (פעם אחת), ואז להריץ.
5. **לרנדר, להסתכל, לתקן** (קונטרסט כותרת, מיקום בועה על הפנים, גדלים).
6. לנקות את `_tmp_*.html` ולפתוח למשתמשת את התיקייה.
